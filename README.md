# Beyond the Maps of Men

Project-management hub for meetings, planning, research, presentations, papers, files, decisions, and task tracking.

## Repository Map

- `docs/meetings/` - agendas, meeting notes, and action items
- `docs/planning/` - roadmap, milestones, schedules, and project strategy
- `docs/files/` - file inventory and links to large external assets
- `docs/presentations/` - deck outlines, presentation notes, and links to deck files
- `docs/papers/` - research notes, paper summaries, and citations
- `docs/decisions/` - decision records for major project calls
- `tasks/` - task board and lightweight status tracking
- `templates/` - reusable templates for meetings, decisions, papers, and tasks
- `.github/ISSUE_TEMPLATE/` - GitHub issue forms for task management

## Working Rhythm

1. Create or update an agenda before each meeting.
2. Capture decisions in `docs/decisions/` when they affect scope, budget, timeline, or creative direction.
3. Track work in GitHub Issues, mirrored at a high level in `tasks/task-board.md`.
4. Put large files in external storage when possible, then record links and ownership in `docs/files/file-index.md`.
5. Keep presentations and papers indexed so collaborators can find the latest version quickly.

## Status Labels

- `Backlog` - useful, not yet scheduled
- `Ready` - defined well enough to begin
- `In Progress` - actively being worked
- `Blocked` - waiting on a decision, dependency, or asset
- `Done` - complete and reviewed

## GitHub Setup

After creating the GitHub repository, enable:

- Issues
- Projects
- Discussions, if collaborators need async conversation threads
- Branch protection, if multiple people will edit core planning docs
